# HEIC fixture

`iphone-image4.heic` is the 41 KB `image4.heic` sample from
[`dsoprea/heic-exif-samples`](https://github.com/dsoprea/heic-exif-samples).
The upstream repository is distributed with its MIT license; its README notes
that the original image provenance is unknown. This file is retained only as
a small automated decoder fixture and is not user content.
