# Fitician Play Store screenshots

Capture clean screenshots from the signed internal-test build. Use seeded
test accounts only; no real identity, body photo, laboratory document,
medical note, token, or personal metric may appear.

## Required set

Capture portrait phone screenshots for both `fa` and `en`:

- member home;
- workout plan and exercise detail;
- nutrition plan or tracking;
- body-progress privacy controls.

Keep the status bar, navigation treatment, fonts, and dark Fitician visual
identity consistent across the set. Capture at the Play-supported phone
resolution selected for the listing and export lossless PNG files under this
directory using locale-prefixed names such as `fa-member-home.png` and
`en-member-home.png`.

The screenshot set is a release artifact, not a substitute for device
acceptance. Its final files must be reviewed for branding, localization,
privacy, and content-rating consistency before upload.
