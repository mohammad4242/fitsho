# Fitician iOS screenshots

Capture screenshots from the signed internal or TestFlight build, in portrait
orientation, with seeded test accounts. Do not include real identity, body
photos, laboratory documents, medical notes, notification tokens, or private
metrics.

Required locales are Persian (`fa`) and English (`en`). Capture at least:

- member home;
- workout plan and exercise detail;
- nutrition plan or tracking;
- body-progress privacy controls.

Keep the Fitician dark theme, fonts, RTL/LTR direction, safe-area treatment,
and labels consistent with the submitted build. Store approved files under
`screenshots/phone/` using locale-prefixed names such as
`fa-member-home.png` and `en-member-home.png`. This README is intentionally
the only committed screenshot source until an approved capture set exists.
